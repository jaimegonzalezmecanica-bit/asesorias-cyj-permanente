🔧 Solución: Crear Usuario Administrador

⚠️ El problema: Las tablas de la base de datos no se crearon correctamente. Esto pasa cuando la variable DATABASE_URL no estaba configurada antes del primer deploy.

Solución Rápida (2 pasos)

Paso 1: Crear las tablas en Neon.tech

1 Ve a console.neon.tech e inicia sesión
2 Selecciona tu proyecto de base de datos
3 En el menú lateral izquierdo, haz clic en "SQL Editor"
4 Copia todo este SQL, pégalo en el editor y haz clic en "Run": 
-- Crear tabla de usuarios
CREATE TABLE IF NOT EXISTS "User" (
  "id" TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  "email" TEXT UNIQUE NOT NULL,
  "nombre" TEXT NOT NULL,
  "apellido" TEXT,
  "password" TEXT NOT NULL,
  "rut" TEXT UNIQUE,
  "telefono" TEXT,
  "direccion" TEXT,
  "rol" TEXT DEFAULT 'usuario',
  "permisos" TEXT,
  "activo" BOOLEAN DEFAULT true,
  "emailVerificado" TIMESTAMP,
  "ultimoAcceso" TIMESTAMP,
  "intentosLogin" INTEGER DEFAULT 0,
  "bloqueadoHasta" TIMESTAMP,
  "twoFactorSecret" TEXT,
  "twoFactorEnabled" BOOLEAN DEFAULT false,
  "resetToken" TEXT,
  "resetTokenExp" TIMESTAMP,
  "creadoPor" TEXT,
  "createdAt" TIMESTAMP DEFAULT NOW(),
  "updatedAt" TIMESTAMP DEFAULT NOW()
);

-- Crear tabla de sesiones
CREATE TABLE IF NOT EXISTS "Session" (
  "id" TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  "userId" TEXT NOT NULL,
  "token" TEXT UNIQUE NOT NULL,
  "userAgent" TEXT,
  "ip" TEXT,
  "expiresAt" TIMESTAMP NOT NULL,
  "createdAt" TIMESTAMP DEFAULT NOW()
);

-- Crear índices
CREATE INDEX IF NOT EXISTS "Session_userId_idx" ON "Session"("userId");

Paso 2: Crear el administrador

1 Después de crear las tablas, abre esta URL en tu navegador:
TU_SITIO.vercel.app/api/setup
(Reemplaza "TU_SITIO" con el nombre de tu proyecto en Vercel)
2 Verás un mensaje JSON con las credenciales creadas
✅ ¡Listo! Ahora puedes iniciar sesión con:
Usuario: admin@cyj.cl
Contraseña: admin123

¿No funciona? Verifica DATABASE_URL

1 Ve a tu proyecto en vercel.com
2 Haz clic en Settings → Environment Variables
3 Verifica que existe DATABASE_URL
4 El valor debe ser algo como: 
postgresql://usuario:contraseña@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require
